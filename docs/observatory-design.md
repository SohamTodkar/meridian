# Meridian observatory design

The workspace is a dark observatory for intentional study. Muted violet identifies the current path and primary action; teal marks verified progress. The cosmic artwork sits beside an immediate study action, with the curriculum and working controls one scroll away. Typography uses locally bundled Inter for the interface, Fraunces for the cosmic heading, and JetBrains Mono for coordinates. No third-party font requests.

Global motion curtains, scroll interception, telemetry overlays, and automatic onboarding were removed from the active shell. Native scrolling and page navigation stay responsive. New surfaces include the overview, interactive map, focus room, daily checklist, source-based research desk, cloud settings, public visitor mode, and owner authentication.
